# Simulador-Escala-Bombeiros

## Descrição do Problema
Simular a escala de plantões de uma equipe de bombeiros para uma semana, garantindo que cada dia tenha pelo menos 2 bombeiros disponíveis e nenhum bombeiro trabalhe mais de 5 dias.

## Requisitos
- Distribuir os bombeiros disponíveis nos dias da semana.
- Garantir no mínimo 2 bombeiros por dia.
- Limitar o trabalho de cada bombeiro a 5 dias por semana.

## Exemplo de Uso
Entrada: lista de bombeiros e dias da semana.

Saída:
Escala gerada: Segunda [Ana, Bruno], Terça [Ana, Carla]...
Está válida: true
